# Data

This folder contains the primary survey data used in the thesis:

**Gen Z Adoption of AI in Banking: Evidence from Malaysia**

The study collected primary data from Malaysian Gen Z respondents using a structured questionnaire.

The full-scale dataset contains responses from **633 respondents**. The questionnaire measures:

- Perceived Usefulness (PU)
- Perceived Ease of Use (PEOU)
- Attitude Towards AI in Banking (ATT)
- Perceived Risk (PR)
- Perceived Trust (PT)
- Intention to Adopt AI in Banking (INT)

The survey also contains demographic information such as age, gender, employment status, education level and AI usage frequency.

A separate pilot-study dataset contains **34 responses** used to evaluate questionnaire reliability before the full-scale study.

## Files

- `ai-banking-survey-data.xlsx` — main survey dataset
- `pilot-study-data.xlsx` — pilot-study dataset

## Data Collection

The study used a quantitative, cross-sectional survey design and convenience sampling.

The main analysis was conducted using PLS-SEM in SmartPLS 4.
