# Analysis

This folder documents the statistical analysis used in the thesis:

**Gen Z Adoption of AI in Banking: Evidence from Malaysia**

The study applies an extended Technology Acceptance Model (TAM) to examine the factors influencing Malaysian Gen Z's intention to adopt AI in banking.

## Analytical Workflow

The analysis was conducted primarily using **SmartPLS 4** and includes:

- Measurement model assessment
- Indicator loading assessment
- Internal consistency reliability
- Convergent validity
- Discriminant validity
- Variance Inflation Factor (VIF)
- Structural model assessment
- Path coefficient estimation
- Hypothesis testing
- Mediation analysis
- Effect-size analysis
- Bootstrapping with 5,000 subsamples
- R-squared evaluation

## Constructs

The structural model includes:

- Perceived Usefulness (PU)
- Perceived Ease of Use (PEOU)
- Attitude Towards AI in Banking (ATT)
- Perceived Risk (PR)
- Perceived Trust (PT)
- Intention to Adopt AI in Banking (INT)

## Key Model Result

The model explains approximately **59.9% of the variance** in intention to adopt AI in banking.

All six hypothesised relationships were statistically significant.
