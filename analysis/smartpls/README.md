# SmartPLS Model

This folder contains the SmartPLS model used for the thesis:

**Gen Z Adoption of AI in Banking: Evidence from Malaysia**

The model applies Partial Least Squares Structural Equation Modelling (PLS-SEM) to examine the relationships among:

- Perceived Usefulness (PU)
- Perceived Ease of Use (PEOU)
- Attitude Towards AI in Banking (ATT)
- Perceived Risk (PR)
- Perceived Trust (PT)
- Intention to Adopt AI in Banking (INT)

The structural model was assessed using SmartPLS 4 with bootstrapping based on 5,000 subsamples.

The analysis includes measurement-model assessment, reliability and validity testing, path coefficients, mediation effects, effect sizes and explanatory power.
